# Moonrunner

Moonrunner is a modulation plugin designed to add motion, rhythm, and evolving movement to sound. It focuses on subtle pulse, drifting modulation, and rhythmic variation that brings tracks to life.

Moonrunner is an open-source project built for producers and developers who enjoy shaping movement as part of the sound.

---

## Features

- Modulation focused on motion and rhythm
- Smooth LFO-driven movement with musical response
- Designed for subtle motion or pronounced modulation
- Simple controls with wide creative range
- Lightweight and responsive

Moonrunner is not about static sound. It is about flow.

---

## Philosophy

Moonrunner was built around one idea:

Movement creates energy.

Sound that never moves can feel lifeless. Moonrunner introduces motion that feels natural, rhythmic, and intentional. It works best when modulation becomes part of the performance rather than an afterthought.

If it feels too subtle, increase the depth.  
If it feels too obvious, slow it down.
