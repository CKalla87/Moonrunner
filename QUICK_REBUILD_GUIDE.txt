METHOD 1: Using Xcode (Recommended - Most Reliable)
═══════════════════════════════════════════════════════════════

For each plugin (GAINFORGE, Ghostline, Noctave, Obsidian Space):

1. OPEN PROJECT:
   - Go to: /Users/christopherkalla/Software Projects/[PluginName]
   - Open: Builds/MacOSX/[PluginName].xcodeproj in Xcode

2. SELECT SCHEME:
   - Top of Xcode: Click scheme dropdown
   - Choose: "[PluginName] - AU" or "[PluginName] - VST3"

3. SET TO RELEASE:
   - Scheme dropdown → "Edit Scheme..."
   - Build Configuration → "Release"
   - Click "Close"

4. SET ARCHITECTURES:
   - Click project name (blue icon) in left sidebar
   - Select project (not target)
   - "Build Settings" tab
   - Search: "architectures"
   - Set "Architectures" to: "Universal (Apple Silicon, Intel)"
   - Set "Only Active Architecture" to: "No"

5. BUILD:
   - Press: Cmd + B
   - Wait for "Build Succeeded"

6. REPEAT:
   - If plugin has AU + VST3, build both schemes
   - Then move to next plugin
